# 一座国际机场是如何建成的？

180秒中文工程科普动画，React + TypeScript + Remotion；1920×1080、30fps、8场景、25镜头。

项目与完整中文使用说明见 [airport180/README.zh-CN.md](airport180/README.zh-CN.md)。

```bash
cd airport180
npm ci
npm run typecheck
npm test
npm run studio
npm run render
```

当前为无配音版，附独立旁白及编辑时间SRT；中文字体、许可证和Blender预渲染底片随源码提供。完整视频和含.blend的工程ZIP另行通过Google Drive交付。
