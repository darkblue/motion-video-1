# 中文旁白逐镜头稿（待TTS时长复核）

000–007s｜当航空需求快速增长，原有机场可能逐渐达到容量上限。
007–014s｜政府和机场业主据此提出新机场建设议案。
014–020s｜批准启动研究，并不意味着马上开工。
020–027s｜咨询团队首先预测需求，研究选址与建设条件。
027–036s｜随后确定跑道、滑行道、机坪和航站楼的空间关系。
036–045s｜可研、总体规划与初步设计逐步形成工程方案。
045–053s｜咨询机构根据方案编制初步投资估算。
053–060s｜投资估算用于预算、融资和投资决策。
060–065s｜但估算、合同中标价和最终结算价并不相同。
065–073s｜本片以业主设计、施工总承包招标为例。
073–082s｜业主组织施工总包及工程师服务招标，评估技术与报价。
082–090s｜随后分别签署设计咨询、工程师服务和施工合同。
090–095s｜工程师审查承包商文件，但双方不因此直接签约。
095–102s｜施工前后，设计团队持续细化航站楼各专业图纸。
102–112s｜建筑、结构、机电和弱电系统需要协同设计。
112–120s｜BIM检查能够提前发现管线碰撞和空间冲突。
120–125s｜问题解决后，相关图纸按合同程序提交审查。
125–133s｜设备采购前，供应商准备技术资料，由总包统一报审。
133–140s｜工程师核对技术规范，不符合要求的资料必须修改。
140–145s｜完成必要确认后，总包才能按约组织相应采购。
145–153s｜现场施工通常是多专业、多区域交叉推进。
153–161s｜土建和机电条件具备后，机场专用设备陆续安装。
161–170s｜之后还要完成设备测试、系统联调和综合验证。
170–176s｜机场还需要运营准备、联合演练和必要的监管批准。
176–180s｜完成交付，机场才真正迎来首航。
